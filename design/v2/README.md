# House Care V2 design sources

This folder contains authored design sources for the V2 retro-vector system. Runtime-ready assets live under `public/brand/v2` and future runtime primitives will live under `src/visual`.

The governing design rules are in `House-Care-v2-Retro-Vector-Design-System.md` and `docs/V2_IMPLEMENTATION_CONTRACT.md`.

Phase 2 establishes brand, typography, semantic tokens and asset organization only. Procedural primitives/patterns are intentionally deferred to later phases.
