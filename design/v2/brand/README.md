# House Care V2 brand sources

The V2 identity uses a compact geometric house + sparkle mark and a retro display-serif wordmark. It follows the 70/30 rule: operational UI remains modern and clear while branding and authored artwork carry the mid-century print character.

## Rules

- No dense halftone in launcher-sized marks.
- Wordmark text remains text; it is not converted to vector outlines.
- The compact mark must remain recognizable in one color.
- Runtime exports are mirrored in `public/brand/v2/`.
- Base authored palette: warm paper, cream, dark teal, teal, mustard, coral and restrained turquoise.
