# v1.2.0 Phase 2 — Overview & routine workflow

Built from the user-supplied `v1.2.0_FLOW_AND_FINISH_SPEC.md` on top of the Phase 1 canonical cleanliness foundation.

## Included

- Overview replaces Today; `/today` redirects to Overview.
- One deduplicated Overview query for overdue, due-now, later-today, finished, and 7-day Upcoming work.
- Critical regular-cleanliness cards with account-level count/threshold preferences.
- Finished is collapsed by default.
- Exact-action Undo for Complete, Skip, Reschedule, and Reassign; after-completion successors are reversed with the source action.
- Routine Pause, Resume, and End lifecycle controls.
- Advanced `Refresh to` control (10–100%, default 100%).
- Refresh-only edits do not retire/regenerate occurrences.
- Fresh Sage semantic token foundation and five-item primary navigation.
- Actions and Supplies remain accessible from Routines.

## Not in this phase

Home room-status/Start-room work, Analysis redesign, theme presets/custom palette, Manrope/Phosphor/motion/illustration pass remain later v1.2 phases.
